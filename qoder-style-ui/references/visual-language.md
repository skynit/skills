# 视觉语言

## 参考结论

用户提供的界面展示了以下可复用视觉特征：

- 当产品已有桌面外壳时，顶部窗口/菜单区、左侧导航、中心工作区和可选侧栏之间层级清楚。
- 主体是暖白或近白背景，文字为柔和黑；分区主要靠 1px 边框、浅灰底和留白，而不是厚阴影。
- 导航与列表行紧凑，图标为细线单色，选中态是低对比灰面。
- 操作控件尺寸克制：小号菜单按钮、胶囊状态标签、绿色开关、单色圆形发送按钮。
- 少量点阵纹理、统计条和分组行通过留白组织，信息结构比装饰更突出。
- 高信息密度的连续内容采用文档式排版，而不是把每条内容都包成聊天气泡或大卡片。

这些是视觉语法观察，不代表 Qoder 的私有实现、完整组件清单、页面结构或功能契约。设置页、账户页和对话区可以作为观察样本，但本 skill 不为任何产品规定页面内容。

## 设计目标

用六个词约束设计决策：

1. **安静**：低饱和中性面，强调色面积小。
2. **紧凑**：默认 36–44px 控件高度，12–16px 常规间距。
3. **可扫描**：标题、说明、状态和控制形成稳定列。
4. **桌面感**：已有外壳保持稳定分区和长期可用的框架。
5. **文档感**：高信息密度内容采用可阅读的文档节奏。
6. **一致**：相同角色使用相同表面、文字、边框和状态外观。

约束：

- 交互强调只使用一个蓝系。
- 危险面使用 `danger` 的低透明背景与同色文字，不把整行涂红。
- 数值使用主文字色，标签使用 muted；不要让所有数字都变成强调色。
- 状态必须同时带文字或图标，例如“已连接”“不可达”“未实现”。

## 字体

- 拉丁与界面主字体：`Inter` 或项目已有无衬线字体。
- 中文 fallback：`Noto Sans SC`，再退到 `system-ui` 和系统 sans。
- 正文和控件：13–14px，行高 1.45–1.55。
- 辅助信息：12px，行高 1.45。
- 区块标题：15–16px，600 字重。
- 页面标题：20–24px，600–700 字重。只有真正的页面标题使用更大字号。
- `letter-spacing: 0`；禁用负字距。
- 长路径、模型名、分支名和邮箱允许 `overflow-wrap:anywhere`；单行控件使用 ellipsis 时同时提供 `title` 或详情入口。

## 密度与形状

- 标题栏：40–44px。
- 左侧导航：216–256px；窄屏可收为 64–72px 图标栏或抽屉。
- 当现有内容本身就是单列阅读结构时，常用内容宽为 720–840px；不要为一个原本全宽的表单强行套窄列。
- 分组圆角：8–10px；行内按钮 6–8px；图标按钮 6px。
- 信息较多的列表行可高 52–64px；普通紧凑行 32–40px；触控场景目标点击区域至少 40×40px。
- 行内图标 16–18px；导航图标 16px；空态主图标 20–24px。
- 普通阴影只用于浮层：`0 8px 24px rgb(0 0 0 / 8%)`，暗色下降低透明度和强度。
- 分区之间的主要手段是背景、边框和 16–32px 留白，不是层层套卡。

## 已有外壳的视觉语法

以下规则只在产品已经存在对应区域时应用，不要求新增这些区域。

### 顶部外壳

- 左侧可放应用图标、返回/前进和菜单；中间保持低强调；右侧是窗口控制或应用级操作。
- 顶部栏高度固定，按钮不可因标题长度改变位置。
- Web 应用没有原生窗口控制时，不伪造最小化/关闭按钮。

### 左侧导航

- 保留现有导航顺序，不为视觉风格增删入口。
- 分组标题使用 11–12px、muted/faint 色，左对齐。
- 条目高度 32–36px，图标与文字间距 10–12px。
- 当前项使用 `surface-muted` 和主文字；hover 只做轻微提升。
- 已有 Beta 或状态标签放在条目右侧，不挤占标签宽度。

### 主工作区

- 页面内容、标题和入口沿用现有信息架构，只调整字号、间距、表面和边界。
- 主工作区根据现有功能独立滚动；固定导航和已有工具栏保持稳定。
- 普通内容不使用悬浮卡片；重复项和真正独立的工具面板才使用边界容器。

### 右侧上下文栏

- 已有侧栏宽度通常为 280–320px；与主区用 1px 分隔线分开。
- 保持现有内容，不做装饰性卡片堆叠。
- 在 `<= 1100px` 时按项目已有响应式策略收起或换成抽屉，不压缩主区到不可读。

## 主题与风格维度

### `data-theme`

只管理颜色：

- `light`：暖白面、柔和黑文字。
- `dark`：暖深灰面、低眩光文字。

不要在 `dark` 中自动改用紫色或蓝黑渐变。保持同一色相关系。

### `data-style`

只管理密度与形状。需要多风格时再实现全部值：

| 值 | 行高 | 间距倾向 | 圆角 | 形态 |
|---|---:|---|---:|---|
| `neutral` | 36px | 12–16px | 8px | 默认 |
| `compact` | 32px | 8–12px | 6px | 运维、长时间使用 |
| `soft` | 40px | 16–24px | 10px | 低密度、引导感 |
| `sharp` | 36px | 12–16px | 2–4px | 更技术化 |
| `dense` | 30–32px | 6–8px | 4–6px | 表格、日志、审查 |

风格不得改变语义色、信息层级或可访问名称。

## 背景纹理

- 点阵纹理只适合非常有限的头部、空区域或品牌区域。
- 使用极低对比度的径向圆点；不要覆盖正文、列表行或输入控件。
- 纹理不能成为唯一视觉焦点，也不适用于每个页面。
- 禁止用渐变球、模糊光晕和装饰性插图替代结构。

## 动效

- 120–180ms 用于 hover、选中、开关和焦点。
- 200–260ms 用于侧栏展开、右栏切换和浮层进入。
- 只动画 `background-color`、`border-color`、`color`、`opacity` 和少量 `transform`。
- 不通过动画改变布局宽度来制造持续重排。
- `prefers-reduced-motion` 下移除非必要动画。

## 反模式

- 整页铺满白色大卡片，再在卡片内继续套卡片。
- 每个列表行都做成独立卡片，产生大量阴影和重复边界。
- 所有标签都是圆角胶囊，或所有图标按钮都没有 tooltip/aria-label。
- 用大片蓝色、渐变、玻璃模糊制造“AI 感”。
- 用假图表、假 Token 消耗、假在线状态填满页面。
- 已有主区两边同时放固定宽度栏，导致 960px 宽度不可用。
- 文字与控件抢空间，造成行高跳动、换行错位或横向滚动。
