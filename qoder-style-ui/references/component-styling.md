# 控件视觉规范

本文件只定义“长什么样”和“视觉状态如何变化”。控件的功能、数量、排列和信息架构由目标产品原有设计决定。

## 设计系统层级

建议分成四层，方便统一样式又不侵入业务：

1. **Foundation**：颜色、字体、间距、圆角、阴影、动效和层级。
2. **Atoms**：按钮、图标按钮、输入框、选择器、开关、标签、头像和提示气泡。
3. **Composite**：列表行、工具栏、表头、分组面板、消息内容、代码块和图表容器。
4. **Product surface**：目标产品原有页面。只套用视觉规则，不重写页面职责。

如果项目已有类似分层，沿用现有名称。不要为了采用这套风格新建一套与现有组件并行的组件库。

## 表面与层级

- 应用背景、主工作区、次级面和浮层使用四级中性表面，不要所有区域都是纯白。
- 普通内容区使用边框或背景差异分层；只有浮层、菜单和对话框使用明显阴影。
- 同一区域内避免连续嵌套多个带边框的容器。
- 选中态使用低对比灰面；hover 只比默认状态提高一档，不使用高亮蓝底。
- 浮层视觉：

```css
background: var(--q-surface-elevated);
border: 1px solid var(--q-border);
border-radius: var(--q-radius-md);
box-shadow: var(--q-shadow-overlay);
```

## 文字层级

- 主文字：`var(--q-text)`，用于标题、正文和关键值。
- 次文字：`var(--q-text-muted)`，用于说明、辅助动作和时间。
- 弱文字：`var(--q-text-faint)`，只用于分组标签和占位，不用于关键状态。
- 文字字号使用 12、13、14、16、20、24px 等稳定档位，不做 viewport 缩放。
- 同一卡片或列表内，标题与说明的字重差不超过两级。
- 长文本默认允许换行；固定单行区域使用 ellipsis，并提供 title 或详情入口。

## 图标

- 使用 16px 或 18px 的细线图标作为控件内图标，20–24px 用于空态或强调。
- 图标颜色跟随文字语义，不单独引入第二种高饱和强调色。
- 图标按钮必须有稳定方形点击区域，视觉图标可以小于点击区域。
- 不把 emoji 当图标，不用不同笔画粗细的图标混排。
- 新图标优先从 lucide 或项目现有图标库选择。

## Button

- 默认按钮：中性浅底、1px 边框、6–8px 圆角、30–36px 高。
- 主按钮：蓝色实底或蓝色文字；同屏只保留一个最明确的蓝色主操作。
- 次按钮：中性底色，不通过粗边框制造层级。
- 危险按钮：浅 danger 背景 + danger 文字 + 图标或明确文字。
- hover 改变背景或边框；active 不缩放整个布局；focus 使用统一 focus ring。
- 禁用态降低对比度，但文字仍需可辨认；不可用原因应通过项目原有方式展示。

## IconButton

- 视觉尺寸 28–32px；点击区域尽量达到 32–40px。
- 默认无底色，hover 使用 `surface-muted`，激活/选中使用 `selection`。
- 必须有 `aria-label`；陌生图标提供 tooltip 或 title。
- 工具栏中的多个图标按钮保持同一尺寸和间距。

## Input 与 Textarea

- 输入框使用 1px 边框、6–8px 圆角和 `surface-elevated` 背景。
- 单行高度 30–38px；多行输入允许增长但有最大高度和内部滚动。
- 占位文字使用 faint 色，不能替代可见 label 或 accessible name。
- focus 使用边框 + 轻量 focus ring，不能只靠光标表示。
- 错误态使用 danger 边框和错误文字，不能只把背景变成红色。
- 只读态使用 muted 背景，不伪装成可编辑控件。

## Select 与 Menu

- 选择器视觉高度与按钮一致，文字 12–13px。
- 右侧 chevron 保持 12–14px，不随内容拉伸。
- 菜单使用 elevated 表面、1px 边框和少量阴影。
- 菜单项高度 30–36px，图标与文字间距 8–12px。
- 选中项使用低对比面或左侧标记，避免整行高饱和蓝。
- 长选项使用 ellipsis，并在 tooltip 或详情中显示完整值。

## Switch

- 典型视觉尺寸为 36–40px 宽、20–22px 高。
- 关闭态使用中性边框/表面，开启态使用 success 色。
- 滑块保持白色或 elevated 色，并保留 1–2px 边缘对比。
- 状态变化必须同时通过 `aria-checked` 和可见状态表达。

## Badge 与状态

- 小标签高度 18–22px，字号 11–12px，圆角 4–6px。
- 中性标签用于分类和 Beta；语义标签只在状态真实存在时使用。
- success、warning、danger 使用低透明背景 + 同色文字。
- 状态标签必须带文字，例如“可用”“降级”“不可达”，不能只放色点。
- 同一行内标签数量保持克制，避免变成彩色胶囊墙。

## 列表与行

- 行高通常 32–40px；信息较多的行可到 52–64px。
- 行之间优先使用 1px subtle 分隔线，不用独立卡片和阴影。
- hover 使用整行浅色背景；选中态比 hover 再高一档或增加细标记。
- 左侧图标列、主内容列和右侧控件列使用稳定网格。
- 主内容列允许收缩和换行；右侧控件不能被文字推挤跳动。
- 行内说明与标题属于同一信息块，不要分散到屏幕两侧。

## 表格

- 表头字号 12px、muted 色、500 字重，背景与正文略有差异。
- 单元格字号 12–13px，行高紧凑，使用 subtle 横线分隔。
- 数字列右对齐或使用等宽数字；长文本列有明确的最大宽度。
- hover 高亮整行；选中状态不覆盖 readability。
- 状态和操作列有稳定宽度，避免数据变化让表格抖动。

## Tabs 与分段控件

- 使用文字或图标 + 短标签，不用大号胶囊按钮。
- 当前项以文字颜色、底部线或低对比底表达，不只依赖颜色。
- 同组分段控件高度一致，宽度按内容或等分策略固定一种。
- 键盘焦点与选中状态是两套视觉，不可混为同一种样式。

## 面板与分组

- 分组外框只出现一次；内部子项使用分隔线。
- 分组标题 12–14px、muted/faint 色，位于内容外侧或顶部。
- 背景差异优先于阴影；普通面板不使用悬浮卡片效果。
- 同一页面只使用一种主要圆角档位，避免 4px、8px、14px 随机混排。

## 代码块

- 使用 elevated 或 muted 表面，1px 边框，6–8px 圆角。
- 代码字体 12–13px，行高 1.55–1.7。
- 只允许代码块内部横向滚动，整个页面不横向滚动。
- 语法颜色低饱和；即使没有颜色也能阅读。
- 复制等操作按钮保持低强调，默认不必一直显示高对比按钮。

## 图表

- 图表背景与所在表面一致，不额外套装饰性卡片。
- 轴线、网格线使用 border-subtle；数据序列使用低饱和语义色。
- 标签字号 11–12px；容器高度稳定，避免数据刷新导致跳动。
- 颜色担当区分手段时，同时提供文本、形状或直接标签。
- 空态、loading 和错误外观由项目原有状态模型决定，本 skill 只规定它们的中性视觉处理。

## 视觉状态

统一检查以下状态，但不改变原有行为：

- default
- hover
- active / selected
- focus-visible
- disabled
- danger
- loading
- empty
- error

状态颜色只是表现层。状态的文案、触发条件和业务含义仍由目标项目维护。

## 桌面外壳的视觉处理

如果产品已经有标题栏、侧栏、主工作区或上下文栏，只调整以下视觉属性：

- 标题栏 40–44px，使用 1px 底边或浅背景分层。
- 侧栏 216–256px，选中项使用低对比面，分组标签使用 faint 色。
- 主工作区使用最亮的普通表面；只有浮层比它更高。
- 可选右栏使用 1px 左边框和略次级表面。
- 外壳尺寸必须稳定，不因标题、状态文字或长路径变化而跳动。

这里定义的是已有布局的外观，不代表要求新增侧栏、右栏或标题栏。

## 响应式视觉

- 不使用 viewport 字号缩放。
- 收窄时优先减少留白、隐藏低频说明或收起已有侧栏，不缩小核心文字。
- 固定格式的按钮、图标、状态标签和工具列必须有稳定尺寸约束。
- 长内容通过换行、ellipsis、内部滚动处理；禁止页面级横向溢出。
- 焦点环不能被 `overflow:hidden` 裁切。
