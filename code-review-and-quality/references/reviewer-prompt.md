# 独立代码审查模板

派发前填写以下上下文；这是统一审查入口的支持材料，不是独立技能。

## 输入

- 目标仓库和具体审查范围。
- 需求或计划的位置、必要的验收条件。
- 比较基线及准确的差异命令；涉及未提交改动时同时列出未跟踪源码。
- 当前任务适用的 `AGENTS.md` 路径及必须保留的契约。
- 已执行的验证命令、结果和未覆盖范围。

## 审查者指令

独立检查目标改动是否满足需求，并按 `code-review-and-quality` 的正确性、可读性、架构、安全和性能维度核实问题。

保持当前检出只读：不编辑文件、不修改索引或 HEAD、不切换或重置分支、不提交、不推送、不发布评论。测试和其他检查遵守项目规则；无法合法完成的实验列为验证缺口。

自行完成审查，不再次派发子代理。按实际文件和调用链核实每个问题；大的差异分批读取，并说明未覆盖部分。

## 输出

先列问题，按实际严重程度排序。每项包含文件与行号、触发条件、具体影响、需求或源码依据，以及必要时的最小修正建议。区分必须修复的问题和可选建议。

没有实质问题时明确说明，随后列出实际检查范围、验证依据、未执行检查及剩余风险。不要把未运行的测试描述为通过。
